# Original simulation package

This is the original source archive for spLeakage 0.1.0.9003, recorded in the
retained simulation metadata. The `package/` working tree is 0.1.0.9004, which
adds subsequent geographic and large-pair-sampling fixes. Its variogram fitting
function is identical to the original function; the source archive preserves
the exact earlier files as well. The supplementary material describes the
historical checks of both versions.

The newer public spCVAudit package is separate from both of these research
implementations. Use the pinned reproduction instructions for the paper.
