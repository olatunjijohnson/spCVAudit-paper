\section*{Code, data and reproducibility}
\begingroup\urlstyle{same}\emergencystretch=2em
The public reproduction repository, \url{https://github.com/olatunjijohnson/spLeakage-paper}, provides the experiment designs, random seeds, analysis code, saved results, figure scripts and archived \texttt{spLeakage} source versions used for the computations and reproduction checks. Manuscript numbers and tables are generated from those results. The Jura data are distributed with \texttt{gstat} and documented by \citet{goovaerts1997geostatistics}; the saved export retains all 359 site measurements and their original training--validation assignments. The application code includes the projection, log transformation, fold assignments, predictions and covariance-fitting checks.

The companion R package \texttt{spCVAudit}, available at \url{https://github.com/olatunjijohnson/spCVAudit}, implements the distance and correlation diagnostics, weighted targets, scheme comparisons and Gaussian reference calculations. Documentation and worked tutorials are at \url{https://olatunjijohnson.github.io/spCVAudit/}. The reproduction repository retains the original computational implementation so that subsequent package changes do not alter the reported results.

The simulation calculations ran on the University of Manchester's Computational Shared Facility (CSF), using R 4.5.0, CAST 1.1.1 and ranger 0.16.0. The supplementary material (Section~\ref*{supp-sec:reproduction}) describes the local environment, checks between environments and reproduction of the simulation studies and Jura application. Source checksums identify the versions used.
