\section*{Code, data and reproducibility}
The accompanying files provide the experiment designs, random seeds, analysis code, saved results, figure scripts and package source. Manuscript numbers and tables are generated from those results. The Jura data are distributed with \texttt{gstat} and documented by \citet{goovaerts1997geostatistics}; the saved export retains all 359 site measurements and their original training--validation assignments. The application code includes the projection, log transformation, fold assignments, predictions and covariance-fitting checks. A permanent public code and data archive remains to be assigned before submission.

The simulation calculations ran on the University of Manchester's Computational Shared Facility (CSF), using R 4.5.0, CAST 1.1.1 and ranger 0.16.0. The supplementary material (Section~\ref*{supp-sec:reproduction}) describes the local environment, checks between environments and reproduction of the simulation studies and Jura application. Source checksums identify the versions used.
