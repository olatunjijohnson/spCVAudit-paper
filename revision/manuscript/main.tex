Not applicable.

\bmhead{Data availability}
The Jura soil data are distributed with the R package \texttt{gstat} and documented by \citet{goovaerts1997geostatistics}. The saved export, which retains all 359 site measurements and their original training--validation assignments, the simulation designs, random seeds and all saved results are available in the public reproduction repository, \url{https://github.com/olatunjijohnson/spCVAudit-paper}. Manuscript numbers and tables are generated from those results.

\bmhead{Code availability}
The reproduction repository, \url{https://github.com/olatunjijohnson/spCVAudit-paper}, provides the analysis code, figure scripts and archived source versions of the original implementation used for the computations (an R package developed under the working name \texttt{spLeakage}), together with the application code for the projection, log transformation, fold assignments, predictions and covariance-fitting checks. It retains the original computational implementation so that later package changes do not alter the reported results. The companion R package \texttt{spCVAudit}, available at \url{https://github.com/olatunjijohnson/spCVAudit} with documentation and tutorials at \url{https://olatunjijohnson.github.io/spCVAudit/}, implements the distance and correlation diagnostics, weighted targets, scheme comparisons and Gaussian reference calculations.

\bmhead{Author contributions}
Olatunji Johnson is the sole author and was responsible for conceptualisation, methodology, software, analysis, interpretation and writing.
